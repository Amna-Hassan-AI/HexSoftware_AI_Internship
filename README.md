# HexSoftware AI Internship - Project 1
## Emotion Detection AI App

This project is a part of my AI Internship at HexSoftwares. It is an AI-powered application that analyzes the sentiment of text inputs and classifies them into different emotional states.

### Features:
- **Sentiment Analysis:** Detects if a message is Positive, Neutral, or Negative.
- **Urdu & English Support:** Capable of processing both languages.
- **Interactive UI:** Built using Gradio for a user-friendly experience.

### Tools Used:
- Python
- TextBlob (for Natural Language Processing)
- Googletrans (for translation)
- Gradio (for the Web Interface)
- Google Colab
